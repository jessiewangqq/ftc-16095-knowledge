# 自动程序开发与标定

用于 Pedro 自动路线、底盘标定、动作接入和自动排错。开始前核对当前依赖版本，下面的入口已按项目 Pedro 3.0.2 与 tuning 1.0.1 检查。这里的完整标定指 Pedro 自动行驶配置；视觉、射手和输送还需分别核对，见知识库 [硬件标定](https://github.com/jessiewangqq/ftc-16095-knowledge/blob/main/hardware/CALIBRATION.md)，其中历史参数按当前代码复核。

## 先分清几个名字

| 名称 | 用途 |
|---|---|
| AutoTune 网页 | 在机器人控制器上运行的标定界面 |
| Mecanum Tuner | 麦克纳姆底盘电机配置 |
| Pinpoint Tuner | 定位轮方向、型号和偏置等配置 |
| Foresight Tuner | 测量行驶速度、减速与控制参数，最后生成 ForesightConfig |
| AutoTune 内的 Tests | 定位、直线、曲线、保持位置等验证 |
| Driver Station 的小写 test | 使用参数执行已有自动路线；不负责生成标定参数 |
| pedro/Constants.java | 保存底盘、定位与 Foresight 三类配置 |

已有匹配当前车辆、验证过的完整配置时，可复用并做受影响的回归检查；无需每次重复全套标定。若配置缺失，不用任意数值或删除启动检查来绕过。

## 实车标定如何进行

1. **准备当前项目和车辆。** 确认控制器安装了含 Tuning 注册的版本，设备名、四个驱动电机和 Pinpoint 接线相符。车辆在实际使用的地垫上标定；速度、减速步骤会自动移动，需要预留前方、左侧、回程和旋转空间。指定一人负责 Driver Station 的 STOP。
2. **连接网页。** 电脑连机器人网络，浏览器访问 `http://机器人实际IP:10158/`。Control Hub 常用入口为 [AutoTune](http://192.168.43.1:10158/)；它是机器人局域网地址，不是外网服务。打不开时先核对网络、实际 IP、控制器程序和依赖是否已安装。
3. **先确认底盘和定位。** 若配置未完成，按 Mecanum Tuner、Pinpoint Tuner 流程完成后，复制各自 Java 导出，替换 Constants 中对应完整声明，重新构建安装。Pinpoint 导出可能采用英寸，原配置可能使用毫米，数值必须和单位成套保留。完整导出会将原先对 DriveConstants 的引用变为独立数值；手动 Drive 仍使用 DriveConstants。同步核对同一硬件的设备名、电机方向、定位轮方向与偏置，统一来源或显式换算，避免自动和手动两套配置不一致，并回归手动驾驶。
4. **检查方向。** 在 AutoTune → Tests 中明确选择 **Localization Test 或 Pose Test**；此时不要沿用默认 Line Test，它需要 Foresight 配置，而这两个定位测试不需要。从零朝向开始，前进应增加 x，向左横移应增加 y；核对旋转方向和位移量。定位不正确，先修配置，再做 Foresight。见 [官方定位检查](https://pedropathing.com/docs/pathing/tuning/localization)。
5. **选择 Foresight Tuner。** 按网页逐步运行并确认每步说明，不把它当作会自动改好源码的一键按钮。每步结束并确认电机停止后，按下个动作需要重摆车辆；不在运动中搬车。具体按钮和运行提示以安装版本网页为准。
6. **保存 Java 结果。** 流程完成后打开 Java 标签，复制完整的 `public static ForesightConfig foresightConfig = ...;`，替换 `pedro/Constants.java` 中原来的完整声明；不是把省略号或示例数字填进去。保存标定日期、车辆配置、测试条件和结果，再提交、构建、安装。
7. **验证结果。** 先检查定位及直线路径，再验证实际自动路线涉及的转弯、到位和停止。Line Test 会往返重复，需主动停止。不是所有 Tests 菜单都必须做完，但本次路线依赖的能力必须有记录。见 [官方测试说明](https://pedropathing.com/docs/pathing/tuning/test)。

网页入口、十项测量及 Java 导出说明见 [官方 Foresight 文档](https://pedropathing.com/docs/pathing/tuning/foresight)。当前项目 [Tuning.java](https://github.com/pengjinDaniel/FTC-16095-FatDragon-2027-Public/blob/7e3ef88704a21512805587e041eb78827e04da54/TeamCode/src/main/java/org/firstinspires/ftc/teamcode/pedro/Tuning.java) 已注册四个流程；不重复添加同名注册。

### Foresight 测量时车会做什么

当前项目流程依次测量：前进最大速度、左横移最大速度、前进自然减速、左横移自然减速、转向制动、转向控制、前进制动、左横移制动、前进位置控制、横移位置控制。制动步骤可能反复往返，转向步骤会原地旋转；测速度到达指定距离后可能继续滑行。

项目输入默认前段距离为 48 英寸（约 1.22 米），制动段为 36 英寸（约 0.91 米），后者至少 15 英寸（约 0.38 米）。这些是测量行程，不是所需空地边界，需额外留出车身和滑行距离。速度输入默认 30，单位按算法为英寸/秒，不要当成厘米或电机功率。只在看懂步骤后根据场地调整；不能靠缩到极小距离得到可靠参数。

若实际运动与说明相反、定位不随车变化、将越过可用场地或程序报失败，停止并保存当前步骤、报错和配置。当前实现遇无效测量会中止；不能跳过报错却写“标定完成”。完整 Foresight 导出位于流程末尾。具体依据见 [本项目 ForesightTuner.java](https://github.com/pengjinDaniel/FTC-16095-FatDragon-2027-Public/blob/7e3ef88704a21512805587e041eb78827e04da54/TeamCode/src/main/java/org/firstinspires/ftc/teamcode/pedro/procedures/ForesightTuner.java)。

## 一条路线怎样拆成可开发的任务

先用队员能解释的动作表说明每一段，字段可以按实际需要裁剪：

| 段落 | 车要做什么 | 开始条件 | 完成条件 | 最长等待与失败处理 | 现有能力或需要补的代码 |
|---|---|---|---|---|---|
| 到射击位 | 从确定起点驶向目标点 | 定位就绪、起点正确 | 位置和朝向在本车验证范围内 | 逾时结束该段并按策略停止或降级 | Pedro 路径与完成判断 |
| 第一轮射击 | 对准当前有效目标并送球 | 目标、转速、俯仰满足条件 | 按任务要求完成送球并确认实际结果 | 无目标或未达速不能无限等待 | Shooter、Transit 与自动动作适配 |
| 翻转后衔接 | 确认翻转，选择下一有效目标 | 有可用的本方状态证据 | 下一目标、朝向和射击条件已确定 | 状态未知时按有限等待与失败策略处理 | 状态判断、目标切换及去重 |
| 下一轮取球或射击 | 根据余球和时间继续 | 路线、球量与剩余时间允许 | 对应动作通过 | 时间不足不启动来不及结束的新阶段 | Intake、路径并行动作 |

这只是拆解格式，不代表这台车已经实现这些判断。阈值与时限应根据规则和实测确定，不能用任意数字冒充标定值。

## 复用 Command 前要读哪里

- 构造参数和 execute 是否依赖 Gamepad：自动阶段没有驾驶员按键输入，不能直接复用等待 RT 的条件。
- 调度器 requirements 是否覆盖实际写入的子系统：并行路径和吸球只在资源允许时组合。
- INIT、START、正常结束、取消与 DS STOP 分别做什么：动作不应意外在准备阶段输出；取消后不能残留送球或驱动请求。
- isFinished 是否可达、等待是否有截止：定时送球的毫秒数不一定包含前面的准备等待。
- 谁写驱动电机、谁持有位置估计：Pedro 行驶与 Drive 瞄准要明确控制权，检查场地坐标转换与单位。当前版本 Drive 构造器会重置 Pinpoint 的位置和 IMU，不能在自动途中为复用射击临时新建 Drive 而忽略这个副作用。
- Shooter 自适应所用的距离、速度反馈、俯仰表是否与实车相符：只有 ready 并不能证明命中。

先复用接口和算法，必要时添加薄的自动适配层；不要复制一整套手动逻辑后让两套代码分别演化。

## 两次有效翻转的验收

两次送球命令不等于两次 TIP。先记录第一次真实翻转、翻转后的目标变化和耗时，再接第二轮；每轮都能解释使用了哪个目标、球来自哪里、什么情况下停止。记录所测阵营、起点、球数、代码与参数版本、逐次结果。只测红方不能写成红蓝都通过，只有一次成功不能写成稳定。

没有实车条件时，可完成代码、离线测试和操作准备，交付中明确剩余的实车检查；不虚构成功率。
