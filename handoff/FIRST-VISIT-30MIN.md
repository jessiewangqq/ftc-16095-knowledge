# 用 30 分钟了解现在做到哪

这次先弄清四件事：车上是哪版程序、亲眼见到哪些动作、最影响比赛的三个问题、下一步由谁在什么时候做什么。

完整时间安排见 [30 分钟现场确认](../plan/FIRST-30-MINUTES.md)。到场准备机器人、控制端、开发电脑、球和可演示场地，请操作、程序以及能说明机械电控情况的同学参加。

## 带走一份具体记录

| 要记录的内容 | 现场填写 |
|---|---|
| 车号、手动和自动入口、红蓝选择 | 待填写 |
| 车上程序与源码能否对应，代码完整 SHA | 待确认 |
| 未共享的代码、参数和最近的失败记录 | 待确认 |
| 亲眼看过的手动动作与次数 | 待填写 |
| 自动实际 TIP 数、用时、失败时怎样退出 | 待填写 |
| 其他人能否拿到代码、构建并继续操作 | 待确认 |
| 本周真实可用的车、场地和训练时段 | 待填写 |
| 比赛确切日期、通知与规则版本 | 待确认 |

结果只写“看到一次”“有重复记录”“本次失败”或“未演示”，不要凭口头描述填百分比。一次演示成功还不是整场稳定。

离开前把最重要的三件事写入[任务看板](../plan/BOARD.md)，确定谁做、谁帮忙检查、何时再看结果。30 分钟里没有测完的内容，另约时间做正式测试。
