# P2 取球、反向与 RB 卡球处理

谁做 / 谁能接着做：待认领，认领后将名字填到[唯一任务看板](../plan/BOARD.md)。本卡不另存任务进展。

## 为什么做

让取球、卡球处理、松开与恢复都符合操作手预期，给 [P3](P3-BALL-LIMIT.md) 留下真实球数。前提为 P0 和 P1 的停止保障。

## 当前已知

公开版已有 LT 取球、LB 反向、RB 卡球处理。RB 是右肩键，RT 是右扳机；按住 RB 时取球与输送反向、射手停止。松开会退出该模式，随后行为取决于其余输入和默认命令。车上具体效果待确认。

## 接下来做什么

1. 和机械/电控同学确认反向功率、最长连续时长、负载限制、球量、挡板位置、停止时延与允许的卡球模拟方法，不猜参数、不锁死电机。
2. 拆开做：空车单球吸入 → 松开 → 受控退出 → 短时 RB → 清点残留 → 再吸入。先不混入射击。
3. 填下面按键表，再测组合。若决定改变默认行为，先写新预期再改代码，并同步操作卡。

| 输入 | 需要确认的行为 |
|---|---|
| RB 按住，其他键松开 | 按已确认方向反向，射手停止；长按不反复切换模式 |
| 松 RB，LT/RT/LB 都松开 | 退出卡球处理；不能承诺所有电机全停，射手可能恢复默认预热 |
| RB＋LT，再松 RB 保持 LT | RB 优先；退出后是否恢复吸球，与操作卡一致 |
| RB＋RT，再松 RB 保持 RT | 打断/取消送球；是否重新准备或发射，明确恢复条件 |
| 松 LT，计数已满 | 公开控制仍可能反向，不能笼统写成所有动作停止 |
| 任意阶段 DS STOP | 结束运行并停止带电动作，核对实际电机和舵机；处理实物前先 STOP |

## 怎样算通过

吸入、反向、恢复方向正确且可重复，残留球单独清点，不把计数清零当排空。采用[逐项示例记录](../tests/RB-UNJAM-EXAMPLE.md)：正常可控卡球处理连续 5 次、空载 5 次，RB＋LT 与 RB＋RT 各 3 次；初始化/处理中/恢复后各 1 次 DS STOP；受影响红蓝手动循环各连续 5 轮；另一人至少独立复现 1 次。LT、LB 基本动作按普通动作建议各重复 5 次，并另测 LT＋RT。

以上为队内建议次数。此项涉及取球、送球、发射和停止，需 **2 位非作者 review，其中 1 位熟悉实车**；关键失败先修复重测。
