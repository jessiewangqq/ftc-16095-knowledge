# P7 不依赖视觉场地坐标的备用射击

谁做 / 谁能接着做：待认领，认领后将名字填到[唯一任务看板](../plan/BOARD.md)。本卡不另存任务进展。

## 为什么做

定位方案受阻时，仍能在已标定位置由人对准、用固定转速与角度受控发射。它是备用手动能力，不能当作自动已完成。

## 当前已知

公开版 `Shooter PID` 测试入口可作为基础，不创建 Vision；原 RB 控制挡板，与主赛 RB 卡球处理不同。`Practice Blue` 仍用定位计算距离，不是这种独立备用。车上是否已有另一个备用入口待确认。

## 接下来做什么

1. 复用 P1—P3、P5 和 P8 基础配置；先保留一个固定射击点与一套参数，不扩大范围。
2. 明确备用入口，统一或清楚标注按键，尤其消除 RB 差异导致的误操作；核对 Dashboard 等比赛配置。
3. 不建立视觉场地坐标，由操作手对准，测试发射、取消、卡球处理、停车和 STOP；红蓝分别测。
4. 演示主方案失败后停车、STOP、选择备用、INIT/START 的实际步骤。切换后若残留球仍在，按 P3 确认；新建 Intake 的计数为 0 不能当作排空。
5. 复核切换后的驾驶方向、初始化机构动作，并纳入 P8 全入口检查。

## 怎样算通过

- 选定点普通动作按 5 次建议重复，满足预先约定的实际命中与停止要求；明确只在已测位置使用。
- 未建立视觉场地坐标仍能完成完整动作，不能暗中依赖旧坐标或调参电脑。
- 残留球、取消和恢复有办法，不绕过控球数量、合法目标或终场停止要求。
- 两位同学都能按操作卡切换并运行。核心控制 2 人 review，通过后才能作为候选比赛备用。
