## 出发前：资格、机构和程序

规则项，依据[第 3 章 V1，I301–I303](https://ftc-resources.firstinspires.org/ftc/archive/2027/game/manual-03)与[第 12 章 TU05](https://ftc-resources.firstinspires.org/ftc/archive/2027/game/manual-12)：

- [ ] 完整机器人、操作控制台及准备使用的各套机构均纳入检查；没有把未经检查的机构直接加上车。
- [ ] 实测起始尺寸、自支撑状态和最大展开尺寸；展开有物理限制（R102、R103、R105）。
- [ ] 对照第 12 章逐件核对电机、舵机、控制器、电池、供电和传感器型号；只看代码类名不能确认实际硬件合法。
- [ ] 主电源开关可安全接近；线缆、锐边、夹伤风险及球的安全取出方式已检查（R201–R203、R603）。
- [ ] 队号与联盟标识清楚、牢固；RC / DS 名称、无线和设备设置按规则检查（R401–R403、R705、R711）。
- [ ] 修改后是否需要复检已确认。一般代码修订不必自动重检；若显著改变尺寸、合法性或安全性，应重新确认（I303）。

队内项，记录放在[硬件配置](../hardware/CONFIGURATION.md)、[发布记录](../releases/REGISTRY.md)和[测试记录](../tests/TEMPLATE.md)：

- [ ] 实车安装版本与发布记录一致，不靠“应该是最新的”判断。
- [ ] 确认工作区干净（没有未提交的改动）后，再构建、安装；记录提交编号、参数和配置。
- [ ] 主干合并之后，已在这台车上重新做整车测试；单功能通过不能代替整车测试。
- [ ] 断电重启后，AUTO / TELEOP、硬件映射、比赛配置均能正常使用。
- [ ] 驾驶员亲自完成了取球、发射、卡球处理、停车和 DS 停止操作；知道出现问题时怎样暂停和恢复。
- [ ] 电池、接头、紧固件、手柄和备件检查完成，并保留可恢复的已测版本。

## 无线与比赛配置

规则项，依据[第 12 章 R704、R705、R711](https://ftc-resources.firstinspires.org/ftc/archive/2027/game/manual-12)和[第 5 章 V1，E301、E302](https://ftc-resources.firstinspires.org/ftc/archive/2027/game/manual-05)：

- [ ] 正式比赛时，除 DRIVER STATION 外的电脑等设备已断开机器人 Wi-Fi。
- [ ] 额外日志 / 数据流服务、连续视频流已按 R704 关闭；重启后仍符合要求。
- [ ] 没有用“把 Dashboard 网页关掉”代替核对机器人端服务。
- [ ] 没有擅自建立热点或其他无线网络；维修区调试也遵守现场网络规定。
- [ ] 若现场指定频段或信道，已按工作人员要求设置。

## 每场开始前

依据[第 10 章 TU05，§10.3](https://ftc-resources.firstinspires.org/ftc/archive/2027/game/manual-10)、[第 11 章 TU07，G304、G305](https://ftc-resources.firstinspires.org/ftc/archive/2027/game/manual-11)：

- [ ] 读赛程确认本场红 / 蓝联盟、队友、场次与上场时间。
- [ ] 与队友说清起点、自动路线、取球区、FLOWER 分工和停车位置。（队内项）
- [ ] 起点合法，接触围墙、完全位于本方半场；不在 LOADING ZONE，不接触 FLOWER 或进入其计分体积。
- [ ] 机器人处于合法起始尺寸；INIT 完成后完全静止，不附着、缠绕或悬挂于场地结构。
- [ ] 正确预装 4 个 POLLEN；摆放满足接触机器人及半场条件。
- [ ] AUTO / TELEOP 选对；运行 AUTO 时已开启 DS 的 30 秒计时器，并完成允许的 INIT。
- [ ] 操作手和投球同学知道 NECTAR 已解锁数量、最后 60 秒限制，以及先落装载区地垫再取球的要求。（操作准备）

## 比赛过程与结束

- [ ] AUTO 不用手柄修正机器人；不干扰对方自动；转换阶段没有电力驱动运动（G401–G403）。
- [ ] 实际控球总数不超过 4，不控制对方 NECTAR（G407、G408）。
- [ ] 向朝上的 CELL 投球；NECTAR 入 FLOWER 等到最后 60 秒（G417、G410）。
- [ ] 人员投球按解锁与落地要求进行（G425–G427）。
- [ ] 终场及时停止；裁判要求停用时按 DS 停止并放下手柄（G404、G413）。
- [ ] 等待工作人员允许后再接近或取走机器人；不擅自影响计分。（按现场工作人员指示）

以上 G 条款详见[第 11 章 TU07](https://ftc-resources.firstinspires.org/ftc/archive/2027/game/manual-11)。

队内赛后记录：

- [ ] 写下实际 TIP、停车、卡球、误吸、掉线等现象；看不清的写“未确认”，不补猜测。
- [ ] 把问题关联到任务；不要赛后立即把所有参数都改掉，先保存当时版本与配置。
- [ ] 修改后重新测试，再决定是否作为下一场版本。参见[发布检查](../releases/CHECKLIST.md)。

## 有争议时怎么问

规则或判罚疑问走赛事 Question Box 等正式问询流程，由至多两名代表沟通，其中至少一名学生（T301）。资格赛、淘汰赛、决赛的问询时限不同，按 T302；不要把“建议三场之内询问”当成所有情况统一的硬截止。现场不能要求裁判用队伍视频或照片重新判分（T401）。自家电池、程序或机构故障也不自动获得重赛（T201）。依据：[第 13 章 V1，§13.2–§13.3](https://ftc-resources.firstinspires.org/ftc/archive/2027/game/manual-13)。

本场具体报到、车检、作品集与评审时间尚未取得，见[待确认通知](SOURCES.md)。
