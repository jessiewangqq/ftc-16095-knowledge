## 四种证据，不能混着说

| 说法 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 代码里已经写了 | 能指出实现位置、输入和输出 | 车上一定按预期动作 |
| 电脑上能构建 | 这台电脑能生成 APK 安装包 | 参数正确、车能得分 |
| 离线检查通过 | 合成输入下，被检查的计算或流程符合断言 | 接线、摩擦、命中率和整场稳定性 |
| 实车测试通过 | 在记录的版本、配置和条件下完成了测试 | 其他版本、其他配置也通过 |
