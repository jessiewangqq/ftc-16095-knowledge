# 从这里安排下一次训练

**11 月 4 日训练已确认：**先看[自动训练任务、分工与分支](2026-11-04-AUTO-TRAINING.md)，再到[看板](BOARD.md)更新实际进展；现场新情况写入[当日日报](../daily/2026-11-04.md)。

1. 第一次到场，用[30 分钟检查](FIRST-30-MINUTES.md)看车上版本与真实动作，先找出最影响比赛的三个问题。
2. 打开[任务看板](BOARD.md)，确认谁来做、谁能接着做、下一次何时看结果。当前进展只在这页维护。
3. 按[参考排期](MILESTONES.md)预约真实用车时间，再打开对应[任务卡](../tasks/README.md)。先写预期和测试条件，再改程序。
4. 测完保存代码完整 SHA、参数和[测试记录](../tests/TEMPLATE.md)，按[合并门槛](../tests/MERGE-GATE.md)请同伴检查；下周另做整场验收。

原参考排期以 2026-11-03 为起点；11 月 4 日的目标、人员与可用时间按上述当日安排执行。比赛具体日期等正式通知；公开源码分析不能证明车上进展。精确开练时间、装车版本和测试结果仍由现场填写。

自动目标是本车 **30 秒争取 2 次有效 TIP**。离墙是中间动作，独立短离墙只能当练习或失败备用。时间不够时先减少没有现成机构支持的扩展，不把低目标写成高目标已经完成。
